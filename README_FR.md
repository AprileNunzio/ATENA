# A.T.E.N.A. - Distributed AI Operating System

## 🚀 Quoi de neuf dans la Version 4.0.0

Atena 4.0.0 introduit de puissantes innovations pour l'automatisation informatique et l'interactivité de l'interface utilisateur :
- **Intégration Native de Proxmox** : Atena est désormais un administrateur expert de Proxmox VE. Grâce au nouveau module `proxmox_manager`, elle peut communiquer avec les API de votre hyperviseur pour gérer les machines virtuelles et les conteneurs LXC, interroger l'état de santé, effectuer des diagnostics avancés et exécuter des opérations de maintenance.
- **Widgets UI Dynamiques** : Fini les simples réponses textuelles et vocales ; l'agent SysOps est désormais capable de générer des tableaux de bord et des widgets HTML interactifs en temps réel, basés sur les données extraites de vos systèmes, affichés de manière élégante via Tailwind CSS directement dans l'interface de chat.
- **Automatisation SysOps Avancée** : Capacités élargies de l'agent d'automatisation système pour gérer des tâches complexes, avec un raisonnement autonome (ReAct) et une validation intégrée via un moteur d'*auto-critique*.

## 🧠 Qu'est-ce qu'Atena ?

Atena n'est pas un simple assistant vocal, c'est un véritable **Système d'Exploitation d'Intelligence Artificielle Distribué** conçu pour gérer de manière autonome la maison, les serveurs, les environnements de développement et l'infrastructure informatique (SysOps/Proxmox). 

Il se distingue par:
- **Multimodalité complète** : Voix, vision, écran, automatisation et code.
- **Confidentialité par conception** : Fonctionne 100% en local, sans dépendre du cloud.
- **Orchestration Multi-Agents** : Plusieurs agents (SysOps, Codeur, Chercheur, Domotique) collaborent pour résoudre vos problèmes complexes.
- **Génération d'Interface Utilisateur (UI)** : Atena dessine elle-même ses graphiques et tableaux de bord selon le besoin.
- **Réseau P2P Swarm** : Reliez plusieurs appareils et serveurs sans configuration complexe.
